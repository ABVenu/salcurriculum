#### **Scene 1.1**

1. **A travel app shows the exact ticket status from its database. The same phone unlocks when it matches a learned fingerprint. What does this show?**  
   a) Both jobs are Generative AI creating new paragraphs from a prompt  
   b) Both jobs are traditional software following one fixed arithmetic formula  
   c) Fingerprint matching is traditional software; ticket status is pattern-based AI  
   d) Ticket status is traditional software; fingerprint matching is recognition AI  

   **Answer:** d) Ticket status is traditional software; fingerprint matching is recognition AI  

   **Explanation:** Exact records from a database are traditional software. Matching a learned fingerprint (or face) is AI for recognition. Everyday devices often combine both.

2. **Why is a basic chat completion not the same as looking up one stored answer?**  
   a) Chat tools can only draw images and cannot produce any sentences  
   b) The model always stays silent unless you upload a scanned PDF first  
   c) It generates likely wording; it does not fetch one saved correct page  
   d) It is wired to every exam portal and always returns live marks  

   **Answer:** c) It generates likely wording; it does not fetch one saved correct page  

   **Explanation:** Generation is prediction from training patterns. Retrieval is fetching a stored record. A basic LLM is not a librarian and is not connected to private systems unless a product adds that.

3. **Why might a chat tool refuse a very long paste and say the message is too long?**  
   a) The model grew tired and needs rest like a person  
   b) Only a limited amount of tokenised text fits in one request  
   c) Tokens are passwords, so the paste used the wrong password  
   d) Traditional software blocks every sentence longer than five words  

   **Answer:** b) Only a limited amount of tokenised text fits in one request  

   **Explanation:** Models process text as tokens and have a limit on how much fits at once. That is why a clear, focused instruction is easier to follow than a huge unfocused dump.
