#### **Scene 3.1**

1. **Which trigger node would best fit "run every Monday at 9 am"?**  
   a) The "On form submission" trigger  
   b) The "On a schedule" trigger  
   c) The "On webhook call" trigger  
   d) The "Trigger manually" option  

   **Answer:** b) The "On a schedule" trigger  

   **Explanation:** A schedule trigger starts the workflow at a set time.

2. **A form trigger's Test URL works only when...**  
   a) The workflow has been published already  
   b) The Google Sheet is completely empty  
   c) It is during working hours  
   d) You are listening for a test event right now  

   **Answer:** d) You are listening for a test event right now  

   **Explanation:** The Production URL needs Publish; the Test URL needs the editor listening.

3. **Matching the form's Email field to the sheet's Email column in a node is called...**  
   a) Publishing the workflow  
   b) Pinning the data  
   c) Mapping the fields  
   d) Tidying the canvas  

   **Answer:** c) Mapping the fields  

   **Explanation:** Mapping tells the action node which data goes in which column.

4. **A published workflow ran, but the editor shows nothing new. Where should you look?**  
   a) The Executions list in n8n  
   b) The sticky note on the canvas  
   c) The form's Test URL page  
   d) The Help menu in the sidebar  

   **Answer:** a) The Executions list in n8n  

   **Explanation:** Production runs appear only in Executions.

5. **Which of these proves the run really worked?**  
   a) The workflow's name shown at the top of the editor  
   b) Succeeded in n8n and the right row in the sheet  
   c) A green zoom button shown on the screen  
   d) The form page loading properly in a web browser  

   **Answer:** b) Succeeded in n8n and the right row in the sheet  

   **Explanation:** Verify in both tools: the execution status and the data itself.
