#### **Scene 3.2**

1. **Which URL starts working after you publish a form workflow?**  
   a) Only the Test URL, as before  
   b) Neither of the two URLs  
   c) The Google Sheet's own URL  
   d) The Production URL for the form  

   **Answer:** d) The Production URL for the form  

   **Explanation:** Publishing registers the production address.

2. **A sheet column stays empty with Map Automatically. What is the likely cause?**  
   a) The sheet has too many rows for n8n to handle  
   b) The form has too few fields to fill the sheet  
   c) Field names don't exactly match the column headers  
   d) n8n is currently offline for everyone in the class  

   **Answer:** c) Field names don't exactly match the column headers  

   **Explanation:** Automatic mapping matches by name, with no error when a name differs.

3. **What should you do with a practice workflow when you have finished?**  
   a) Leave it published and running  
   b) Unpublish it, or delete it entirely  
   c) Share the form link widely with others  
   d) Add some real customer data  

   **Answer:** b) Unpublish it, or delete it entirely  

   **Explanation:** A published form is open to anyone with the link.
