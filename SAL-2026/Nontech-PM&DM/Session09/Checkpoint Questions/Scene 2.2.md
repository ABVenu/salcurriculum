#### **Scene 2.2**

1. **Where in n8n do you find the list of past workflow runs?**  
   a) The sticky note on the canvas  
   b) The credential screen for logins  
   c) The Executions list in the menu  
   d) The Tidy Up control on the canvas  

   **Answer:** c) The Executions list in the menu  

   **Explanation:** Executions lists each run with its status.

2. **What does a credential store for your nodes?**  
   a) A saved, secure login to an outside app  
   b) A form field and its label on the page  
   c) A schedule for when the workflow should run  
   d) A small sample of test data  

   **Answer:** a) A saved, secure login to an outside app  

   **Explanation:** Nodes reuse the credential to connect to the app.

3. **Are the keys Email and email treated the same in JSON data?**  
   a) Yes, they are always identical  
   b) Only when shown in the Table view  
   c) Only when they come from form data  
   d) No, since JSON keys are case-sensitive  

   **Answer:** d) No, since JSON keys are case-sensitive  

   **Explanation:** A wrong capital letter in an expression returns nothing.
