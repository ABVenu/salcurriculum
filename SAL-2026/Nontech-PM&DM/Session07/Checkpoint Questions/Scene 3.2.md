#### **Scene 3.2**

1. **What is the safest source for checking a figure in a draft?**  
   a) The original document it came from  
   b) The AI's own repeated answer  
   c) A colleague's memory of it  
   d) Any similar-looking website online  

   **Answer:** a) The original document it came from  

   **Explanation:** A primary source is the original document, page or person.

2. **An AI invents a source that sounds quite real. What is this called?**  
   a) A small formatting error only  
   b) A fact that is outdated  
   c) A hallucinated citation or reference  
   d) A mismatch with brand voice  

   **Answer:** c) A hallucinated citation or reference  

   **Explanation:** A fluent, specific reference that does not exist.

3. **After rewriting a draft with AI, what must you do before sending it?**  
   a) Send it out right away  
   b) Trust it, since it was already checked once  
   c) Delete the old version of it  
   d) Check it again from scratch  

   **Answer:** d) Check it again from scratch  

   **Explanation:** A rewrite can introduce new errors, so it needs its own check.
