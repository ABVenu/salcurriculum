#### **Scene 3.1**

1. **In data analysis, what is a "hallucination"?**  
   a) AI refusing to answer  
   b) A chart with wrong colours  
   c) An encrypted dataset  
   d) AI stating an unsupported number or cause  

   **Answer:** d) AI stating an unsupported number or cause  

   **Explanation:** Confidently stating a number, trend, or cause the data doesn't actually back up.

2. **Students in study groups get higher grades. What's the safest way to report this?**  
   a) "Associated with higher grades; causation not proven."  
   b) "Study groups cause higher grades."  
   c) "Grades have nothing to do with study groups."  
   d) "Every student must join a study group."  

   **Answer:** a) "Associated with higher grades; causation not proven."  

   **Explanation:** This is a correlation — other reasons could explain both, so "causes" overstates it.

3. **AI says 18 of 675 failures is "about 20%." What should you do?**  
   a) Trust it — AI arithmetic is always right  
   b) Recompute: 18÷675 ≈ 2.7%, flag the gap  
   c) Round up to 25% to be safe  
   d) Remove the metric instead of checking it  

   **Answer:** b) Recompute: 18÷675 ≈ 2.7%, flag the gap  

   **Explanation:** 18 ÷ 675 is about 2.7%, not 20% — always recompute a ratio before repeating it.

4. **A 48-hour backend approval delay — a teammate blames a broken screen. What should you check?**  
   a) Agree and redesign the screen  
   b) Assume AI invented the number  
   c) Whether it's really a backend process, not a UI bug  
   d) Domain logic doesn't matter once verified  

   **Answer:** c) Whether it's really a backend process, not a UI bug  

   **Explanation:** A number can be correct and still be misdiagnosed — check the real cause before proposing a fix.

5. **Which recommendation is decision-ready?**  
   a) "Improve customer retention."  
   b) "Marketing should try harder."  
   c) "The data is interesting; more research needed."  
   d) "Send a SIP prompt within 48 hours; track signup rate for 4 weeks."  

   **Answer:** d) "Send a SIP prompt within 48 hours; track signup rate for 4 weeks."  

   **Explanation:** It names a specific, buildable action and how to check it worked.
