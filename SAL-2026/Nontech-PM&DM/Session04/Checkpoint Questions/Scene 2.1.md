#### **Scene 2.1**

1. **Which is the most targeted question about cancellation data?**  
   a) "Tell me about this data."  
   b) "Which city has the highest cancellation rate, and by how much?"  
   c) "Any patterns here?"  
   d) "Give me insights."  

   **Answer:** b) "Which city has the highest cancellation rate, and by how much?"  

   **Explanation:** Naming a specific comparison and asking for a measurable gap is what makes it targeted.

2. **What is a prompt chain?**  
   a) One long prompt listing every question  
   b) A prompt repeated three times  
   c) A method to encrypt prompts  
   d) Connected prompts, each building on the last answer  

   **Answer:** d) Connected prompts, each building on the last answer  

   **Explanation:** Each prompt reacts to the previous answer — a sharper follow-up, not a bigger single ask.

3. **A student asks which quarter had the highest revenue, then asks which region drove that quarter's growth. What is this?**  
   a) A guided exploratory follow-up  
   b) Zero-shot prompting  
   c) The AI hallucinating a region  
   d) Tokenization  

   **Answer:** a) A guided exploratory follow-up  

   **Explanation:** A follow-up that builds on the previous answer is exactly the guided EDA pattern this lesson teaches.

4. **Region X: 60% conversion (500 customers). Region Y: 65% (12 customers). Why treat Y with caution?**  
   a) A higher percentage is always more trustworthy  
   b) Y's number can't be calculated  
   c) Y's sample is too small to be reliable  
   d) Small samples are always exactly accurate  

   **Answer:** c) Y's sample is too small to be reliable  

   **Explanation:** A percentage built on very few customers can swing wildly by chance.

5. **Variable A spans 15%–95% across groups; B, C, D each span under 8 points. What's the reasonable next step?**  
   a) Treat all four equally  
   b) Investigate A; set B, C, D aside for now  
   c) Ignore A because wide spreads mean broken data  
   d) Discard all four  

   **Answer:** b) Investigate A; set B, C, D aside for now  

   **Explanation:** A wide, consistent spread is worth chasing; near-flat variables are a valid "nothing here" finding.
