#### **Scene 1.1**

1. **Which statement best describes Artificial Intelligence?**  
   a) A person inside the computer who holds opinions and answers in language  
   b) A search tool that always opens one official page for every question  
   c) Software that imitates useful abilities such as language and patterns  
   d) Hardware that stores files and works only when a printer is attached  

   **Answer:** c) Software that imitates useful abilities such as language and patterns  

   **Explanation:** AI is software trained on data so it can handle flexible tasks such as recognising patterns or working with language. It is not a person, not the same as “the internet,” and not a piece of hardware.

2. **How does traditional software usually behave when the input does not match a programmed case?**  
   a) It returns an error, a blank, or an invalid-input message  
   b) It invents a fluent answer so the user is never left waiting  
   c) It always asks a chatbot to invent the missing business rule  
   d) It waits until the user describes their mood in a long paragraph  

   **Answer:** a) It returns an error, a blank, or an invalid-input message  

   **Explanation:** Traditional software follows predefined rules. If the case was never programmed, it fails or reports invalid input instead of guessing.

3. **How does a large language model produce a reply to a prompt?**  
   a) It copies one stored document from a private library  
   b) It reasons with human-like beliefs, goals, and exam fear  
   c) It opens the campus ERP and fetches yesterday’s circular  
   d) It predicts the next piece of text from learned patterns  

   **Answer:** d) It predicts the next piece of text from learned patterns  

   **Explanation:** An LLM generates language by next-token prediction: it estimates what usually comes next, then continues. Search or file lookup is an extra product feature, not the core model.

4. **A chatbot writes a fluent paragraph that names a report, a date, and a statistic that never existed. What is this called?**  
   a) Retrieval, because the model copied an official stored record  
   b) Hallucination, because fluent specific content can still be untrue  
   c) Tokenization, because the reply was split into pieces too early  
   d) Traditional software, because a form rejected an invalid code  

   **Answer:** b) Hallucination, because fluent specific content can still be untrue  

   **Explanation:** Hallucination is confident, specific output that is not true. The model is continuing a plausible pattern, not lying with intent and not fetching a real record.

5. **In the working sense needed for this lesson, what is a token?**  
   a) A small piece of text that the model reads and writes  
   b) A password the model uses to open a user’s mailbox  
   c) A certificate that proves every generated sentence is true  
   d) A hardware chip that stores every page on the internet  

   **Answer:** a) A small piece of text that the model reads and writes  

   **Explanation:** Tokenization is cutting text into those small pieces so the model can process it. You do not need the cutting rules; knowing that text is handled in pieces is enough.
