# SAL — Stimulated Adaptive Learning

## What SAL Is

**SAL** stands for **Stimulated Adaptive Learning**.

SAL helps the student **adopt a path based on their learning**. The session is not one long video. Mentors **bifurcate** the session into parts so the learner can move through **core teaching** and **revision** separately.

---

## How the Session Is Split

Record the session in these clips:

| Family                        | Scene IDs                    | Purpose                                                                  |
| ----------------------------- | ---------------------------- | ------------------------------------------------------------------------ |
| **Main scenes (`.1` family)** | `1.1`, `2.1`, `3.1`, … `X.1` | **Core teaching** happens here                                           |
| **Subscenes (`.2` family)**   | `1.2`, `2.2`, `3.2`, … `X.2` | **Quick revision** of the matching main scene, covering / quiz questions |
| **Doubt resolution scene**    | Once per session only        | Chat-based doubt support for students who did not pass the quiz          |

Example for a 3-scene session:

- `1.1` → core teaching for Scene 1
- `1.2` → quick revision + quiz for Scene 1
- `2.1` → core teaching for Scene 2
- `2.2` → quick revision + quiz for Scene 2
- …and so on
- **Doubt resolution** → recorded **only once** for the whole session (not once per scene)

**Plan the content so everything is covered in the stipulated time** for that scene.

**PPTs for main scenes must be prepared well.**

---

## Interactive Recording Style

The recording should **feel interactive**, as if a live class is happening.

### Start of the session

- Ask: **“How are you?”**
- Reply as the mentor: **“I am doing fine.”**
- From **Session 2 onwards**, also ask: **“How was the previous session?”**

### During teaching

- Read the chats and answer those queries.
- Resolve **all possible questions** that may arise for that topic.

### Quiz time

- **Main scene (`.1`):** allot **5 minutes** for quiz at the end.
- **Subscene (`.2`):** allot **3 minutes** for quiz.

---

## Rules for Main Scenes (`.1` family)

### Scene 1.1 (first scene of the session)

1. Share the **opening slide** that shows the **title and agenda** of the session.
2. **Camera should be off.** Keep this slide for **20 seconds**.
3. **Turn the camera on.**
4. Greet users and start the session.
5. Teach the core content.
6. By the end of Scene `1.1`, allot **quiz time**.
7. Once the quiz is released and the **timer is on**, **camera should be off**.
8. Once the timer ends, **simply end the recording**. Do not say anything.

### Scenes 2.1, 3.1, and later main scenes

1. Start with **camera on**.
2. Directly explain the core part.
3. Run the quiz (**5 minutes**).
4. End the recording (same quiz-end rule: camera off when timer is on; stop when the timer ends, no closing speech).

### Activities during core teaching

- If there are activities, give **sufficient time** for them.
- Keep a **timer on** during the activity.
- **Camera may be off** during the timer.

---

## Rules for Subscenes (`.2` family)

1. Start the subscene with **camera on**.
2. Show **all quiz questions with options on screen**.
3. Opening statement (say this, do not use scene IDs):

   > Still some students have issues in the concept. I will help you by revising the concepts.

4. Quick **revision** of the matching main scene.
5. Cover / quiz questions on that scene.
6. Allot **3 minutes** for quiz.

---

## Rules for the Doubt Resolution Scene

Record this scene **only 1 time per session** (not once per main scene or subscene).

1. Keep **camera on** and start.
2. Opening statement (say this, do not use scene IDs):

   > Since still some students need some support as you didn’t pass the quiz — no issues. The chat support is open. Please ask doubts and get them clarified.

3. **Close the camera.**
4. Keep the **doubt resolution time** slide on screen.
5. End the recording after **5 minutes**. Do not add a closing speech.

---

## Break Rule

After **60 minutes of recording**, in **any** scene, plan a break:

- Allot **5 to 8 minutes** of break.
- Provide a **timer**.
- Camera can be off during the break.

---

## Tech Setup

- Tech stack can be **Zoom** or **OBS**. Either is fine.
- If using **Zoom**:
  - Keep **mic volume to the highest** (input volume at the maximum).

  - Use the **best quality mic** so audio is of best quality.

## Please Note the Non-Negotiables

- Sit in front of a **bright background** so there is **sufficient lighting**.
- There should **not be any disturbance**.
- Keep **mobile silent**.
- Use **annotation** properly: mark on the screen with **arrow marks**, **straight lines**, and **circles** so students focus on the screen.
- If you are using **Zoom** and an **external screen annotator**, **share the entire screen**. If you share only a window, the annotator marks will **not** be recorded.
- **Outfit, hairstyle, and background must stay the same** across every part of the video — same colour of shirt / T-shirt, same hairstyle, same background. This should look like one live session. **Finish the recording in one go.** Do not record scene by scene on separate days.
- **Virtual background must not change scene by scene.** Keep one background for the full session. **Prefer a blurred background** over a changing virtual image.
- **Hide date and time from the screen.** There should be **no date and time** on your laptop screen. Do not show any resources or references that have a date and time on them.
- **Do not share** the Lecture Script, Lecture Notes, GitHub repo, or any other reference material given to you. Those are for your preparation only. **Close them well before the session starts** so they never appear on screen during recording.
- **Do not add any logo or name of any organisation** — including **Masai** or **IIT** — in **any slide or notes**.

---

## What We Provide vs What You Prepare

The following will be **given by us**. Do not rewrite them; use them as the source of truth for the recording:

- **Lecture Notes**
- **Lecture Script**
- **Quiz questions** — generally called **In Class Quiz**

**You** prepare the **presentation** in whatever way is convenient for you — slides or any other presentation format. Teach from our notes and script; the deck is your delivery tool.

---

## What Not to Say On Camera or in Chat

Students should not hear the internal SAL structure.

- Do **not** use words like **Scene 1.1**, **Scene 1.0**, **Scene 2.1**, **subscene**, and similar scene IDs **in the video**.
- Do **not** ask students to type routing codes in chat. Do **not** say things like:
  - “type 1 in chat”
  - “type 0 in chat”
  - “type true / false in chat”
  - or any similar 1 / 0 / true / false / yes-no codes used only for internal routing

  Teach and take doubts in normal language.

Keep scene numbers and routing codes (1, 0, true, false) for your own planning only. Do not speak them on camera or write them as chat instructions.

- [ ] Bright background; enough light
- [ ] Same outfit colour, hairstyle, and background for the full session — record all parts in one go, not on separate days
- [ ] Virtual background does not change scene by scene; prefer blur
- [ ] Date and time hidden; no date/time on the laptop screen or on any resource/reference shown
- [ ] Script, Lecture Notes, GitHub repo, and other reference material closed well before recording — not shared on screen
- [ ] No logo or name of any organisation (Masai or IIT) in any slide or notes
- [ ] Mobile on silent; no disturbance
- [ ] Annotation tools ready (arrows, lines, circles)
- [ ] If using Zoom with an external screen annotator, share the **entire screen** (otherwise annotators will not be recorded)
- [ ] Timers ready (activities, quiz, break)

**Scene `1.1`**

- [ ] Opening slide, camera off, **20 seconds**
- [ ] Camera on → greet (“How are you?” / “I am doing fine”)
- [ ] Core teaching + chat/Q&A
- [ ] Activities with timer (camera may be off)
- [ ] Quiz **5 minutes**, camera off when timer starts
- [ ] Timer ends → stop recording, no talk

**Scenes `2.1`, `3.1`, …**

- [ ] Camera on from the start
- [ ] Core teaching + chat/Q&A
- [ ] Quiz **5 minutes**, then end

**Subscenes `1.2`, `2.2`, …**

- [ ] Camera on from the start
- [ ] All quiz questions with options on screen
- [ ] Opening: “Still some students have issues in the concept. I will help you by revising the concepts.”
- [ ] Quick revision of the matching `.1` scene
- [ ] Quiz **3 minutes**

- [ ] Camera on → opening: quiz not passed, no issues, chat support is open, ask doubts

**Break**

- [ ] After 60 minutes of recording, 5–8 minute timer break (camera may be off)
