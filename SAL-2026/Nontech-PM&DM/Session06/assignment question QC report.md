## Anti-predictability QC

### MCQ letter key

| Q | Correct |
|---|---|
| Q1 | B |
| Q2 | D |

| Q4 | C |
| Q5 | B |

Counts: A = 1, B = 2, C = 1, D = 2. No letter is unused. No letter is always correct.

### MCQ length key

| Q | Longest option | Shortest option | Correct is |
|---|---|---|---|
| Q1 | A (wrong) | C (wrong) | Mid-length (B) |
| Q2 | B (wrong) | A (wrong) | Mid-length (D) |
| Q3 | B (wrong) | D (wrong) | Mid-length (A) |
| Q4 | D (wrong) | A (wrong) | Mid-length (C) |
| Q5 | A (wrong) | C (wrong) | Mid-length (B) |
| Q6 | A (wrong) | C (wrong) | Mid-length (D) |

The correct MCQ option is not the unique longest option on any question, and not the unique shortest option on any question.

### MSQ pattern key

| Q | Correct letters | How many correct | Wrong letter(s) | Longest option |
|---|---|---|---|---|
| Q7 | A, C | 2 | B, D | B (wrong) |
| Q8 | B, D | 2 | A, C | C (wrong) |
| Q9 | A, B, D | 3 | C | C (wrong) |
| Q10 | A, D | 2 | B, C | B (wrong) |

Not the same letter pair each time. Not always two correct. On every MSQ the longest option is wrong.
