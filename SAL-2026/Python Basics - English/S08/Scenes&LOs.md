Session Title: args, kwargs, and Built-in Functions

Part 1: *args and **kwargs
LO1: Explain why *args collects extra positional values passed into a function.
LO2: Demonstrate how to define and call a function that uses *args.
LO3: Explain why **kwargs collects named values passed into a function.
LO4: Implement a function that uses both *args and **kwargs.

Part 2: Built-in functions for lists, strings, sets, tuples, and dictionaries
LO1: Explain a built-in function as a ready-made function Python provides for lists, strings, sets, tuples, and dictionaries.
LO2: Demonstrate list functions such as insert(), extend(), pop(), remove(), sort(), and reverse(), and string functions such as upper(), lower(), strip(), replace(), split(), and join().
LO3: Demonstrate set functions such as remove(), discard(), union(), intersection(), and difference(), tuple functions such as count() and index(), and dictionary functions such as get(), keys(), values(), items(), pop(), and update().
LO4: Implement a small program that uses built-in functions from a list, a string, and a dictionary together.
