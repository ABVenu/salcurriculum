Session Title: Functions in Python

Part 1: Defining and calling a function
LO1: Explain why a function is used to name one job and reuse it.
LO2: Demonstrate how to define a function with def and call it by its name.
LO3: Explain the difference between a parameter and an argument.
LO4: Implement a function that sends a result back with return.

Part 2: Inputs, defaults, and decisions
LO1: Explain how a function can take more than one value, including a default value.
LO2: Demonstrate a function call that uses a default parameter, and a call that overrides it.
LO3: Demonstrate how if and else inside a function choose a result.
LO4: Implement a function for a small problem, such as a bill total.
