Session Title: AI — Introduction to GenAI & LLMs

Part 1: AI
LO1: Explain what artificial intelligence means, using examples such as a spam filter, face unlock, and a chatbot.
LO2: Explain how rule-based software differs from software that generates new text.
LO3: Demonstrate the difference between a tool that only returns a label and a tool that writes new text.
LO4: Implement a classification of everyday tools into traditional software, labelling AI, and generative AI.

Part 2: LLMs and prompting
LO1: Explain what a large language model is, and how it builds a reply by predicting the next piece of text.
LO2: Explain what a prompt is, and how a clearer prompt names the job, the reader, and the length.
LO3: Demonstrate a vague prompt and a clearer prompt on the same task.
LO4: Implement a clearer prompt for a short everyday task, such as a leave message or a simple explanation.

Part 3: Important LLM terms, with a practical demo
LO1: Explain a token, temperature, and hallucination in plain words.
LO2: Demonstrate the same prompt at a low temperature and a high temperature, and how the wording changes.
LO3: Demonstrate a model reply that hallucinates a number, name, or rule that was not in the prompt.
LO4: Implement a check on the demo reply: keep the useful lines, and remove any claim that cannot be verified.
