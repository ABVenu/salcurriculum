Session Title: Data Structures in Python

Scene 1.0: Array[Lists]
LO1: Understand the purpose of lists in Python and how they store multiple elements.
LO2: Demonstrate the use of indexing and iteration to access elements in a list.
LO3: Explain how lists can store different data types and how to determine their length.
LO4: Apply negative indexing and reverse iteration to access elements in a list.
LO5: Illustrate how to manipulate lists using methods like append(), insert(), and extend().

Scene 2.0: Strings
LO1: Define what strings are and explain the concept of indexing in strings.
LO2: Demonstrate how to extract characters from even positions in a string using indexing.
LO3: Explain the immutability of strings and how string concatenation works.
LO4: Apply string slicing techniques to manipulate and access parts of a string.
LO5: Identify and use string methods such as upper(), title(), capitalize(), islower(), and isupper().

Scene 3.0: Sets and tuples
LO1: Explain the concepts of mutability and immutability and their relevance to sets and tuples.
LO2: Demonstrate the creation of sets, their syntax, and unique properties such as storing only unique values.
LO3: Apply set operations like add(), remove(), and discard() and perform list-to-set conversions.
LO4: Identify the immutability of tuples and their differences from lists, including syntax and functionality.
LO5: Perform slicing operations on tuples, including negative slicing, even-index slicing, and list-to-tuple conversions.


Scene 4.0: Dictionaries
LO1: Define the concept and functionality of dictionaries, including their use of key-value pairs and restrictions on duplicate keys.
LO2: Demonstrate the process of creating a dictionary and retrieving values using keys.
LO3: Calculate the number of key-value pairs and the length of elements stored under specific keys in a dictionary.
LO4: Illustrate the iteration process over dictionaries and explain how values can store different data types.
LO5: Apply dictionary functions such as pop(), popitem(), clear(), get(), .keys(), and .values() to manipulate and access dictionary data.
