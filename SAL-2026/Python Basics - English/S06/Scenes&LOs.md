Session Title: Data Structures in Python — Sets, Tuples & Dictionaries

Part 1: Sets and tuples
LO1: Explain why a set keeps only unique values and why a tuple stays fixed after it is created.
LO2: Demonstrate how to create a set and add one value with add().
LO3: Demonstrate how to create a tuple and read an item by its index.
LO4: Implement a list-to-set conversion to drop duplicates, and a list-to-tuple conversion to lock the values.

Part 2: Dictionaries
LO1: Explain a dictionary as key-value pairs, and why a key cannot be repeated.
LO2: Demonstrate how to create a dictionary and read a value using its key.
LO3: Demonstrate how to loop through the pairs in a dictionary.
LO4: Implement a small dictionary by storing a few pairs and changing one value by its key.
