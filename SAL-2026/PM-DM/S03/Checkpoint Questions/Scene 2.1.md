#### **Scene 2.1**

1. **Which statement best describes a Minimum Viable Product (MVP)?**  
   a) The smallest offer that still delivers the core job and can be tested  
   b) A cheap unfinished app whose only purpose is to look broken on purpose  
   c) A logo plus a long site that looks like a company but tests nothing  
   d) Every feature from the later vision, shipped before anyone can try the job  

   **Answer:** a) The smallest offer that still delivers the core job and can be tested  

   **Explanation:** An MVP is the least you can show that still does one job and can be put in front of people. Looks, a broken toy, or the full vision are not that test.

2. **What belongs on an early MVP include list?**  
   a) Payments, maps, ratings, and login so it already looks like a full product  
   b) Dark mode and a custom logo, even if they do not change what you learn  
   c) Only the pieces that help you learn about the core job in this version  
   d) Anything a simulated comment mentioned, including extras it invented  

   **Answer:** c) Only the pieces that help you learn about the core job in this version  

   **Explanation:** If a piece does not help you learn about the core job this week, it stays off the include list. Polish and invented extras are excludes.

3. **What is iteration on a prototype?**  
   a) Rebuilding the whole site because a simulated user asked for a larger product  
   b) A small bounded change from evidence, then a recheck of the same questions  
   c) Changing the colours first, then deciding later whether the offer got clearer  
   d) Adding every requested feature so that nothing has to be parked for later  

   **Answer:** b) A small bounded change from evidence, then a recheck of the same questions  

   **Explanation:** Iteration is a bounded change from a finding, then a check. Rebuilding, decorating first, or shipping every request is not iteration.

4. **After you change the page from a finding, what should you do next?**  
   a) Celebrate if an earlier simulation once said the old page was already perfect  
   b) Start a new product line so the old questions no longer have to apply at all  
   c) Hide the edit and skip checking whether the earlier stall on the page is gone  
   d) Re-run the same test questions on the new page text, and judge only that text  

   **Answer:** d) Re-run the same test questions on the new page text, and judge only that text  

   **Explanation:** After an edit, ask the same questions of the new text. If you cannot say what you will re-test, you are decorating.

5. **A change blocks understanding or the next step, fits the MVP, and is quick. Where does it go?**  
   a) Later, because all clarity work is treated as decoration and should wait  
   b) Ignore, because only invented comments are allowed onto the Now list  
   c) Now: fix it in this sitting so learning about the core job can continue  
   d) Next: only a real user may ever be shown a clearer heading or button  

   **Answer:** c) Now: fix it in this sitting so learning about the core job can continue  

   **Explanation:** Now is for blockers of understanding or the call-to-action that fit the MVP and can be done in this sitting. Clarity beats extra features when time is short.
