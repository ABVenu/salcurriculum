#### **Scene 2.1**

1. **Which statement best describes a prototype?**  
   a) A finished system with login, payments, and every user type  
   b) A twenty-page website with blog, shop, and an about section  
   c) A registered company that already serves paying customers  
   d) An early, incomplete version used to show the idea and learn  

   **Answer:** d) An early, incomplete version used to show the idea and learn  

   **Explanation:** A prototype is for showing and learning, not for running a full service. Login, many pages, and a live company are not what a first prototype is for.

2. **How does a wireframe differ from a landing page?**  
   a) A wireframe is the box layout; a landing page is a real one-page link  
   b) A wireframe is the full product; a landing page is only a colour palette  
   c) A landing page must include login; a wireframe must include payments  
   d) They are the same artefact, so either word can replace the other  

   **Answer:** a) A wireframe is the box layout; a landing page is a real one-page link  

   **Explanation:** A wireframe shows what sits where before decoration. A landing page is one screen with one story and one main action that someone can open.

3. **What should the call-to-action on a first landing page be?**  
   a) Five equal buttons such as Login, Shop, Blog, About, and Contact  
   b) A Learn more label that does not open any real destination  
   c) One next step, as a button or link the visitor can actually use  
   d) A gallery of many images with no request for any action  

   **Answer:** c) One next step, as a button or link the visitor can actually use  

   **Explanation:** One primary CTA names the job (for example join a waitlist) and must work. Extra buttons split attention. A dead “learn more” is not a next step.

4. **What does a website builder let you do?**  
   a) Write a full program before any words are chosen  
   b) Type the page into visual boxes and publish a link  
   c) Skip checking facts the model invented  
   d) Collect official identity numbers as the only form field  

   **Answer:** b) Type the page into visual boxes and publish a link  

   **Explanation:** Tools such as Google Sites, Canva, Carrd, or Durable let you assemble a page without writing a program. You still edit the words and you still avoid collecting private data you do not need.

5. **Why keep an early waitlist form to a few fields such as name, context, and yes/no?**  
   a) A tiny form is enough to act; extra private fields are not needed yet  
   b) Official identity documents must be collected before any headline is written  
   c) A long survey is the only way a button can count as a call-to-action  
   d) Forms are optional if the page uses a dark theme and looks expensive  

   **Answer:** a) A tiny form is enough to act; extra private fields are not needed yet  

   **Explanation:** The form is part of the prototype. A few honest fields let someone act. Passwords, identity numbers, and huge surveys do not belong on a first waitlist.
